# TapFarm

Auto farm cho **Tap Simulator REBORN**: Auto Tap, Auto Hatch, Auto Equip Best, Anti-AFK và webhook Discord báo pet hiếm, kèm UI.

## Chạy

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/Mhna3112/mhnascript/main/TapFarm.luau"))()
```

Tắt: nút **X** trên UI hoặc `getgenv().TapFarm.Stop()`.

Webhook URL nhập trên UI, lưu cục bộ trong `TapFarm_webhook.txt` (không nằm trong repo).
